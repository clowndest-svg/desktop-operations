# 小夜 r124 · 月夜陪伴界面

2026-10-25。Windows 桌面版 r124；Android 0.6.0（12）。

主页以对话为中心，保留用户确认的低饱和写实人物背景、左侧对话和右侧人物构图。品牌标识使用用户提供的原始 logo；写实人物为 AI 生成的独立形象。

## 去哪里找功能

| 想做什么 | 入口 |
|---|---|
| 打字聊天、发附件 | 首页底部输入框、左侧「＋」 |
| 开始语音 | 输入框右侧「语音」，未启用时自动准备语音链路 |
| 新对话、历史 | 对话卡片右上角 |
| 换模型、清空、用量、音色、放大、多模型、上下文和工具开关 | 当前模型名称或「···」→ 对话选项 |
| 画图、视频、提醒 | 右上角「功能」→ 创作与日常 |
| 手机接入、投屏、电脑权限、系统监控/磁盘/清理/进程 | 「功能」→ 设备与文件 |
| 麦克风、朗读和音频状态 | 「功能」→ 语音控制 |
| 皮肤、宠物、扩展 | 「功能」→ 个性与设置 |
| 操作记录、告警、最大化、收进托盘 | 「功能」→ 记录与窗口 |
| 模型配置与其他偏好 | 右上角「设置」 |

功能面板支持搜索，支持 Esc 关闭和键盘循环焦点。告警出现时会在顶栏给出入口。新对话保留原对话；清空仍使用原有确认流程。

## 人物与语音

写实人物使用本地透明 WebP 素材和 Canvas 2D：默认自然待机、眨眼和轻微呼吸；聆听时轻轻侧头，思考时姿态变化。口型来自**实际播放音频的 RMS 电平**，音量越大张口越明显，停顿时收口，打断后立即闭嘴。它是音量驱动的 2D 动画，不是逐音素对齐的视频生成或完整真人数字人模型。

桌面和手机连接电脑后的通话页共用人物渲染器。手机通话新增独立的播放分析器，不使用麦克风电平伪装口型。手机独立模式依赖原生系统 TTS，无法取得原始音频，背景保留待机动作，不声称具有实时口型。

隐藏或移出屏幕时暂停人物绘制；开启“减少动态效果”时停止眨眼和摆动，仍保留表达音频状态所需的口型。

## 图标与素材来源

- 原始 logo：`assets-src/brand/xiaoye-logo.jpg`，由用户提供。网页品牌、消息头像、favicon、Windows exe/托盘/快捷方式、Android 启动图与多密度图标均由此派生。
- 写实人物：`assets-src/brand/portrait.png`、`speaking.png`、`blink.png`，通过 imagegen 内置工具生成。提示词及约束见 [品牌素材说明](../assets-src/brand/README.md)。不使用视频截图中的人物作为项目素材。
- 已研究 [pixi-live2d-display](https://github.com/guansss/pixi-live2d-display)、[lip-sync 分支](https://github.com/zhaoyin0226/pixi-live2d-display-lip-sync) 和 [voqalize/avatar](https://github.com/voqalize/avatar)。这些项目的引擎许可与示例模型许可分开；本轮没有引入其代码、模型、Cubism SDK 或运行时依赖。
- 品牌重建：`python scripts/prepare_brand.py`，Windows 图标：`python scripts/make_icon.py`。资产均随程序本地分发，运行时不下载头像。

## 本轮修复与优化

1. 首页几十个按钮收为可搜索的分组功能入口；聊天高级设置默认折叠。
2. Windows 图标构建改为读取真实 logo，避免重建时覆盖回旧标识；托盘保留麦克风/工作状态提示点。
3. 3D 宠物、趋势图和系统面板按需加载；首页入口 JavaScript 从原先约 1.78 MB 的单包降到入口与共享块合计约 441 KB，重型模块在使用时加载。
4. 补上品牌图片、图标及 Android 资源的发布指纹；二进制按原始字节哈希，避免把图片字节误当 CRLF 文本处理。
5. 修复前端 `source-map-js` 高危依赖问题，常规依赖升级后重新编译与验收。
   同时将 Edge-TTS 从 7.2.8 升至 7.3.1，修复本机实测的上游 403 握手失败；真实中文朗读生成 443,520 字节 PCM，19 个传输分片逐字节回读一致，并驱动新人物口型与打断动作。
6. 保留并核验本轮开始前尚未提交的手机工作台、文档、笔记、会话与原生文件功能。
7. 删除已无引用的旧 HUD 人物组件、脚手架标识和旧语音球样式；历史文档中的版本记录仍按历史记录保留。
8. 补齐 llama.cpp、SDL、LGPL 与 platform-tools 的随包许可文本和来源索引，放在 `_internal/licenses/`。精确 FFmpeg DLL 构建的完整源码复现仍需上游分发方配方，不能把许可文本齐备说成已经复现全部第三方构建。

## 验证与边界

证据在本机 `reports/brand-r124/`：包含前端截图、音频口型、停止回闭、功能搜索、系统面板、整窗聊天、小窗口与减少动态效果的浏览器验收，以及代码质量门禁。浏览器中“试听”为合成 PCM 测试信号，不能当作真实大模型语音内容的验收。

冻结 exe 自检、正式签名 APK 内容及签名、交付 ZIP 全 CRC 和 SHA256、快捷方式读回分别由交付脚本生成证据。仅当实际凭据通过，才能写入最终验收结果。旧产物在新包独立校验通过后清理。

真实云端生图/视频/音色复刻需要用户配置可用服务；本轮不通过假端点声称验证这些账号服务。Android 真机权限、ROM、音频和系统 TTS 仍以真机验收为准。历史的大显存视频生成限制也不会因 UI 更换而消失。
