# 手机端 0.5.0：AI 工作台与本机内容管理

本次扩展针对 Android 手机独立模式：在原有聊天、照片、系统语音、手机动作和电脑遥控基础上，补充内容创作、阅读、学习和整理能力。入口为聊天「＋ → AI 工作台」，空白会话和左侧会话抽屉也能进入。

## 可以直接使用的功能

| 入口 | 新增能力 |
| --- | --- |
| 会话抽屉 | 手机独立多会话、新建、标题及正文搜索、置顶、重命名、归档及移出归档、确认删除 |
| 聊天气泡的「···」 | 修改提问后作为新问题发送、引用、从任意消息新建分支、重新生成并保留原会话、继续追问、精简、转行动清单、保存为笔记 |
| AI 工作台 → 助手 | 日常、写作、翻译、学习、编程、会议、计划和阅读，共 8 种助手；每段会话可保存自定义指令 |
| AI 工作台 → 提示词 | 16 个内置模板，覆盖邮件、周报、纪要、复习卡、口语、计划、行程、食谱和代码审阅；分类筛选、搜索、填写变量、自建及编辑模板 |
| AI 工作台 → 笔记待办 | 离线新建及编辑、标签、置顶、搜索、待办完成及重新打开、导出、交给 AI 阅读 |
| AI 工作台 → 收藏 | 收藏回答、搜索收藏及原问题、再次使用、取消收藏、Markdown 导出 |
| AI 工作台 → 资料备份 | 当前对话 Markdown 导出，手机内容 JSON 备份、校验和确认恢复；资料问答使用说明 |
| AI 工作台 → 偏好统计 | 标准及大字、紧凑操作、最近 10/30/60 条上下文、手机模型工具开关；会话、字数、笔记及存储统计 |
| 抽屉 → 搜索本段聊天 | 搜索关键词、高亮定位、上一个和下一个匹配 |
| 输入框 | 每段独立会话自动保存未发送的文字草稿；切换和重启后恢复 |
| 「＋ → 读文件」 | TXT、Markdown、CSV、JSON、日志和文本代码资料问答；发送前可移除 |

助手和模板使用用户已经配置的兼容模型，不新增订阅或账号。模板、精简、转清单和引用先填到输入框，用户检查并发送后才调用模型。助手选择会创建新会话；同一份资料的后续提问应继续在原会话中进行。

## 内容和模式边界

- 手机独立会话保存在手机本地，电脑遥控仍使用电脑侧会话；切换模式不会把电脑历史当作新的手机会话。既有独立历史首次升级会迁移到新工作区，旧存储保留作迁移来源。
- 普通聊天、资料、笔记交给模型时，会发送到设置中指定的服务商；离线保存笔记不会自动上传。资料正文保存在会话和 JSON 备份中，气泡只显示提问及文件名。
- 历史照片仍仅留图标，不保存图片正文；对含图问题重新生成时，会提示重新选择图片。
- 关闭「允许 AI 请求手机工具」后不发送工具清单，即使模型返回未请求的工具调用也不会执行。开启后，既有需要确认的手机动作仍经过确认闸。
- 本机最多 100 段会话，每段保留最近 60 条消息；最多 200 条收藏、50 条自建提示词、100 条笔记及待办。单条消息及草稿最多 40000 字，自定义指令 2000 字，笔记和资料正文最多 24000 字。
- 文本资料最多 128 KB，要求 UTF-8；PDF、Word、电子表格和压缩包暂不解析。超限或无效文件会给出错误，不能把文件名当作已阅读正文。
- 内容备份上限为 8 MB，不包含模型 API Key、电脑配对令牌、照片二进制或电脑历史。备份包含私人聊天、资料、笔记和草稿，应妥善保存。恢复会替换当前手机内容，须先检查文件并由用户确认；异常文件不会覆盖原记录。
- Android 导出通过系统「另存为」选择目标位置，不申请整个存储盘权限。取消保存不显示成功；网页预览使用浏览器下载。
- 手机上没有新增本地大模型、独立联网搜索或语音复刻引擎；AI 回答能力由实际模型决定。电脑语音通话与电脑音色库仍需连接电脑。

## 验证方式

```powershell
cd frontend
npm test
npm run build:mobile
npx cap sync android
cd ..
node --experimental-strip-types --experimental-vm-modules scripts/test_mobile_runtime.mjs
node scripts/verify_mobile_workspace_ui.mjs D:/AI/XiaoYe/qa/mobile-0.5.0
.venv/Scripts/python.exe scripts/run_gates.py --frontend --out D:/AI/XiaoYe/qa/mobile-0.5.0/gates-final.json
```

浏览器回归使用独立临时配置和假的模型 HTTP 响应，检查真实构建页面、请求正文、迁移、导出、恢复、模板、笔记、待办、分支、草稿、归档和窄屏布局。它不代表真实云端模型质量、Android ROM 兼容性或系统文件选择器已经真机验收。实际 APK 必须另外检查 release 签名、版本和随包资源；构建及交付记录另存于本轮验收报告。

设计参考：[Claude Projects](https://www.anthropic.com/news/projects) 的资料与会话组织，以及 [Gemini Canvas](https://blog.google/products-and-platforms/products/gemini/gemini-collaboration-features/) 的内容工作区；本实现不声称具备它们所有的在线或生成能力。
