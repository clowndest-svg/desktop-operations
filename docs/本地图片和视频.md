# 多语言图片与本地短视频

> r127 完整买家包附带 ComfyUI、独立 Python/CUDA Torch、SD1.5 与 AnimateDiff 模型及视频节点，不需要买家先装 Python 或下载这些权重。本机验证条件为 Windows x64、GTX 1650 4GB；其他显卡/驱动组合仍需对应环境验证。在线音色和云端生成另需网络/账号，详见 [交付说明](交付说明-r127.md)。下文旧轮次耗时仅作历史记录。
>
> r127 视频改为「先生成 512 px 关键帧，再缩放潜空间并以低重绘强度生成动作」；正式档 16 帧 / 256×256 / 8 fps 在本机实测 162.6 秒，解码为 16 帧、2.0 秒，抽帧可辨认主体且不再出现彩色噪声。画面细节仍受 SD1.5/AnimateDiff 与 4GB 显存限制，不宣称达到大模型视频的清晰度。

生图和视频在「功能 → 创作」进入，也可在对话中请求。对话工具直接接收原文，服务层按这条顺序翻成英文：
1. **本地/当前聊天模型**（随包就是本地 Qwen）——**零额外 key、离线可用**，关掉思考（`chat_template_kwargs.enable_thinking=False`）求快；
2. 模型不可用时退到**国内可直连的联网翻译**（阿里云通义千问 Qwen-MT 为主、百度翻译为备，按顺序试、一家不行换下一家）。
自动识别语言并整句翻，避免有限词典漏掉数量、动作、否定或位置关系。**输入已是英文时直接跳过翻译**
（只认 `the/and/with` 这类强英文虚词，无重音的法/西语仍会翻）。
英文原文不改写，提示词权重语法保留；某一路返回异常或译文仍含未翻译文字时换下一路，全失败则
停止生成并把每一路真实原因显示出来，绝不泄露提示词。原文、实际英文和**用了哪一路翻译**会随结果显示。
本地模型那条不需要任何云 key；只有退到联网翻译时才要配 `DASHSCOPE_API_KEY` 或百度 key。视频推理在本机，
也可以把引擎切成自配置的云端 API（见下）。
**翻译快不快是量过的**（r117，本机随包 Qwen3-4B 4096 窗口、就是产品那条 `LocalLlmTranslator` 调用）：
一句 27 字的生图描述 1.0 秒、一句 60 字带数量和否定的视频描述 1.5 秒、12 字的短语 0.4 秒
（那句 60 字的译文实测 53 个输出 token，1.5 秒 → 约 35 token/秒；思考块确认没被触发，`content` 非空）；
同一句再问走内存缓存，0 毫秒。真正确实要等的是生成本身（单张 512×512 二十步实测 22.4 秒、
一段 2 秒短视频 137 秒），翻译只占其中零头。模型如果已经按「空闲自动关」释放了，第一次翻译还要
等它把权重读进来（本轮实测 4.7 秒起来，之前量到的是 5.8~6.5 秒）。
机器翻译和生成模型仍可能误解歧义描述，可以根据显示的译文核对后调整。

视频使用 [AnimateDiff Evolved](https://github.com/Kosinkadink/ComfyUI-AnimateDiff-Evolved)、
[VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) 与 SD1.5 基础模型。
r127 先生成 512px 关键帧，再缩放潜空间并进行低强度动态扩散；关键帧至少 20 步，视频弹窗的步数控制后续动态采样。此流程用于减少基础模型直接从逐帧噪声生成时的画面失真，耗时包括两次采样。低配本地视频仍是短片能力，动作与细节存在模型局限。
分辨率、帧率、时长、步数都可在视频弹窗调整，对话工具也能带这几个参数：

- **默认全部走「自动」**：按本机显卡显存（读自 ComfyUI `/system_stats`）给一档短视频 ——
  4 GB 档＝256×256·8 帧/秒·2 秒（16 帧，r113 实测形状），8 GB 档＝384×384·12 帧/秒·4 秒，
  10 GB 以上＝512×512·16 帧/秒·8 秒。没探测过引擎时按 4 GB 保守处理，弹窗会写明。
- **手动档**：分辨率 256/384/512 方图，帧率 8/12/16/24，时长 2/3/4/8/16/32 秒，步数 12~30。
  要长视频就把时长调大即可。
- **上限按显存截断**：帧数上限从「4 GB 卡 32 帧@256×256 装得下」这一实测锚点外推
  （每百万像素·帧约 950 MB，预算取总显存一半），超出会截到能装下的帧数，
  并在弹窗「这一炉实际会画」和对话回话里明说截到了多少 —— 不会悄悄把 32 秒变成 2 秒。
  外推只有一根锚点，若某组合真机崩了往小一档调。

为 GTX 1650 4GB 使用 lowvram、8 帧上下文和自动分批 VAE 解码。图片与视频共用一把任务锁，
同时请求会提示等待。MP4 在弹窗和对话卡片中播放，也可以打开文件及所在文件夹。
生成途中弹窗有「停止」：置一个共享取消位并向引擎 `POST /interrupt`，轮询循环下一轮读到就中止、
返回「已停止生成」；下一次 generate 开头会 clear，不会被上一次的停止位卡住。另有「重启引擎」：
先 `stop()`（只收本软件起的那个进程，用户自己开的 ComfyUI 绝不动）再按目录重新起并等它答话。

## 云端视频（多家可自填，默认本地）

视频弹窗顶部有三档引擎：**自动 / 只用本地 / 只用云端**，默认落本地（本机那条不需要任何钥匙）。
选「只用云端」或「自动且本机连不上」时，走的是可配置的异步「文生视频」链路：
提交一个建任务请求 → 轮询任务状态 → 拿到下载地址 → 下成 MP4 存进 `视频/`。

视频没有像生图那样能照搬 OpenAI 的 `/images/generations` 公约数：可灵 / 即梦 / 通义万相 / Vidu
各家的建任务地址、请求体字段、任务 id 在哪层、轮询地址怎么拼、成功状态叫什么、视频 URL 藏在哪
都不同。所以这一档**不给某一家写死契约**，而是把链路里每个「接口形状」摊成弹窗「云端 API 配置」里
能自填的格子：建任务地址、钥匙所在环境变量名、模型 id、请求体 JSON 模板（`{{prompt}} {{model}}
{{width}} {{height}} {{seconds}} {{fps}} {{frames}}` 按值插入，别加引号）、额外请求头、
任务 id / 视频地址 / 状态的取法、成功/进行中/失败的状态值。

出厂默认按**阿里通义万相**预置（`wanx2.1-t2v-turbo`，复用项目里已有的 `DASHSCOPE_API_KEY`）。
换别家照它文档逐格改，代码不动。钥匙的**值**只待在你设的环境变量里，
软件只记「住哪个变量」的名字，不落盘、不进交付包、不上传。

诚实边界：这条链路验到**契约层**——用离线假端点跑通了「提交→轮询→下载→落成 MP4」全流程；
但通义万相只是按它公开的异步契约**预置成默认档**，本轮打包环境里没有可用的 DASHSCOPE 账号密钥，
**没拿真账号跑过一次真视频**（和生图云端、云端复刻一个口径）。所以"能不能出片"这句只在契约层成立，
配好钥匙请自己先生成一次确认；别家没钥匙更没法替他验证。
云端按原话直发给服务商（多为中文原生），不强制翻成英文，也不按本机显存截帧数——那是服务商的上限。

排除输入、输出、用户记录、缓存、日志和 Git 元数据。Python 与 PyTorch 为独立运行时，
不打入桌面主进程。模型 SHA256 与 Hugging Face LFS 元数据核对，残缺模型不启用。

## r117→r118：发货那一版是 r118，不是 r117

r117 压完包之后、界面复验之前，读视频弹窗文案抓到一处**买家会直接看到的错词**：
「能不能 Longer/更大」（应为「能不能更长、更大」）。改文案必须重压，所以
`小夜-电脑+手机-r118.zip`（SHA256 `8d27c3cf5abc281f6e291e8f06c4575c8f485557447010b10762136478966279`，
18296.3 MB，54094 条目）才是发货那版；r116/r117 两枚旧包已删。
教训是：**改完面向买家的文案，要在压包之前扫一遍界面上看得见的文案，而不是压完再回头读源码**。

**这一轮验到的（都有当场证据）**：全量门禁 `GATEEXIT=0`（3908 passed / 5 skipped、mypy --strict 392 文件、
`npm run build`）；打包版 exe `--self-check-json` 回 `ok/frozen/round=r118`、14 项 checks 无一失败；
独立全量 CRC 回读 189 秒通过；包内 PYZ 里查到 `LocalLlmTranslator`、`enable_thinking`、`_cancel/cancel`；
包内真正加载的 `index-*.js` 里两句新话在、两句旧话（"先整句联网翻译""翻译需要联网"）与错词都为 0；
**打包版真界面 CDP 复验 PASS**（读的是屏上渲染出来的字：生图/视频弹窗两句新话、
引擎默认亮在「只用本地 AnimateDiff」、三档按钮齐、「重启引擎」在、「停止」按 busy 正确隐藏）；
本地翻译耗时按产品那条链路实测（0.4~1.5 秒、同句缓存 0 毫秒、模型冷启 4.7 秒）。

**还没验到的，别当已验**：
- 云端文生视频仍只到**契约层**——没拿真账号出过一次片（出厂预置的通义万相需要买家自己的 `DASHSCOPE_API_KEY`）。
- 联网翻译兜底那两家（通义千问 Qwen-MT、百度）同样**没用真 Key 跑过**，只有离线假端点验的拼装与切换。
- 「解压双击就能用」只在作者这台机器成立；干净系统的 WebView2 缺失与 SmartScreen 拦截是两条写在交付工具里的提醒，没在干净机上实测。
- 「停止」对**视频那一炉**的真机中止在 r116 验过一次，本轮代码路径没动所以没重跑；对生图的中止同上。
