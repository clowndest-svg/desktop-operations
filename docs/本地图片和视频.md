# 多语言图片与本地短视频

生图和视频都可在顶栏弹窗操作，也可在对话中请求。对话工具直接接收原文，服务层用
Google Translate 自动识别语言并整句翻成英文，避免有限词典漏掉数量、动作、否定或位置关系。
英文原文不改写，提示词权重语法保留；译文未覆盖整段原文、仍有未翻译文字或网络失败时，
停止生成并显示原因。原文、实际英文和翻译服务会随结果显示。翻译需要网络，视频推理在本机。
机器翻译和生成模型仍可能误解歧义描述，可以根据显示的译文核对后调整。

视频使用 [AnimateDiff Evolved](https://github.com/Kosinkadink/ComfyUI-AnimateDiff-Evolved)、
[VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) 与 SD1.5 基础模型，
默认 256×256、16 帧、8 帧/秒、Euler 16 步，支持 16/24/32 帧（2/3/4 秒）。
为 GTX 1650 4GB 使用 lowvram、8 帧上下文和自动分批 VAE 解码。图片与视频共用一把任务锁，
同时请求会提示等待。MP4 在弹窗和对话卡片中播放，也可以打开文件及所在文件夹。

## 本机路径

- 引擎和模型：`D:\AI\XiaoYe\engine\`。
- 构建、测试和缓存：`D:\AI\XiaoYe\build\`、`D:\AI\XiaoYe\qa\`、`D:\AI\XiaoYe\cache\`。
- 新交付包：`D:\AI\XiaoYe\releases\`。
- 既有用户数据继续使用 `JARVIS_HOME` 指定的目录；图片为 `生图/`，MP4 为 `视频/`。
- 打包时本地引擎放到程序旁的 `本地引擎/`，自动发现，不需要再次下载。

引擎子进程使用自身目录下的缓存和临时目录。打包时只复制干净运行时和模型，
排除输入、输出、用户记录、缓存、日志和 Git 元数据。Python 与 PyTorch 为独立运行时，
不打入桌面主进程。模型 SHA256 与 Hugging Face LFS 元数据核对，残缺模型不启用。

## 开发安装和验证

先在非系统盘准备可运行的 ComfyUI 与 SD1.5 checkpoint，然后安装视频组件：

```powershell
./scripts/setup_local_video.ps1 -EngineRoot D:\AI\XiaoYe\engine\ComfyUI `
  -Python D:\AI\XiaoYe\engine\venv\Scripts\python.exe
```

重启引擎，在生图弹窗指定目录和地址。可运行真实双入口验证：

```powershell
.venv/Scripts/python.exe scripts/verify_media_generation.py `
  --engine-url http://127.0.0.1:8190 --output D:/AI/XiaoYe/qa
```

打包时通过 `scripts/place_media_engine.py --round r113 --build-root D:/AI/XiaoYe/build`
落位引擎。模型不进入 GitHub 仓库。
