# r129：历史搜索、置顶与完整导出

2026-10-26 开始实施，2026-10-27 构建交付。桌面 r129，Android 继续使用源码未变的 0.9.1（16）。

## 使用方式

- 对话主页点「历史」，输入标题或正文关键词，搜索全部本机记录；内容匹配会显示附近片段。一次加载 50 场，可以继续「加载更多」。
- 重要会话点「置顶」，需要时勾「只看置顶」。置顶保存在数据库中，重启仍保留，也不会更改原聊天时间。
- 「改名」在弹窗内直接编辑，最多 48 字。「导出」把完整历史写入数据目录下的 `文档/对话/`，包括最早的消息；不受界面 200 条消息显示上限影响。同名文件自动编号，并发导出也不覆盖。
- 「全选已加载」只勾选已经显示的结果。更改搜索或筛选会清除勾选；删除仍需确认。导出保存文字及附件名称，不包含附件文件本体。

## 修复与性能

旧版历史只显示最近 50 场；导出只取最后 200 条，旧对话还可能丢失标题。本轮修复这些边界，并让界面打开失败时保留弹窗和错误信息。历史弹窗改在页面顶层显示，避免被聊天面板裁切；420 px 宽度下按钮可以换行。

列表查询先用排序索引取得一页，再统计这些会话。后台快照只查当前打开的会话，不再反复统计最近 200 场。2,000 场 / 400,000 条合成消息的内存库预热基准，7 次中位数：列表 413.203 → 1.688 ms；3 个已打开会话的快照统计 387.849 → 0.071 ms。该数据不代表其他电脑的界面响应保证；正文子串搜索仍需扫描候选内容。

数据库自动增加置顶字段和排序索引，保留原记录。升级前按既有流程备份用户数据。
