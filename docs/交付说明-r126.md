# r126：修复人物接缝，交付完整本地能力

> 历史候选说明：r126 未完成最终视频验收与交付打包，已由 [r127 交付说明](交付说明-r127.md) 取代；本文保留当时的改动记录。

## 本轮修复

上一版直接按固定坐标裁切生成图集，实际上部分说话帧的人头偏移了约 33 像素，导致嘴部错位和深色头发贴到脸上。现在制作阶段先按眼睛和嘴角配准，再统一 20 个角色的大小和位置；画布边界统一羽化。验收新增所有角色最大开口截图，保留实际 TTS 与停止播放检查，不能再用“数值会动”代替画面验收。

视频候选包的视觉检查发现，基础 SD1.5 直接从逐帧噪声开始时会出现彩色失真，旧的“文件生成成功”检查没有覆盖此问题。现在先生成 512px 关键帧，再进行低重绘强度的 AnimateDiff 动态采样；验收同时保存原始 MP4 和抽帧图，单凭编码成功不能作为画面合格的证据。

完整买家包与作者运行目录分开。买家启动时使用自身 `用户数据/`，不继承作者的路径和服务账号；程序代码相同，交付身份由显式构建元数据区分，并进行独立检查。完整买家包缺少下面任一必要组件会拒绝制作。

## 解压后哪些功能能用

| 能力 | 已随完整包附带 | 使用条件 |
|---|---|---|
| 本地聊天与允许的电脑工具 | llama.cpp、量化模型及应用依赖 | Windows x64、足够内存；电脑控制遵守用户权限 |
| 本地图片 | ComfyUI、独立 Python、CUDA Torch、SD1.5 FP16 | 兼容的 NVIDIA 显卡与驱动；本机 GTX 1650 4GB 实测 |
| 本地短视频 | AnimateDiff 模型、视频节点、编码依赖 | 同上；低配从默认短视频档开始 |
| 离线语音识别 | SenseVoiceSmall、FSMN-VAD 权重 | 麦克风与系统权限；不再先下载约 900MB 模型 |
| 语音朗读与角色搭配 | Edge-TTS、20 个形象与音色绑定 | 在线音色需要联网 |
| 网页界面 | 固定版 WebView2 | 不需要另装 WebView2 或 Python |
| 手机、投屏 | APK、配对服务、adb/scrcpy | 手机设备、配对及对应系统授权 |
| 云端模型、生图/视频、云端声音复刻 | 对应适配入口 | 用户自己的账号、Key、额度及服务可用性 |

因此，“完整解压，在已验证的硬件条件下使用本地功能”与“任意电脑、所有第三方服务都无需配置”是两回事。交付包不含账号或云端额度，也不安装显卡驱动。缺少硬件、权限或账号时界面应显示原因。

## 迁移与运行依赖

生图引擎直接使用随包 Python，移除了作者虚拟环境启动器与配置的绝对路径依赖；本地引擎不继承作者的外部模型配置。启动独立 Python 时会隔离冻结程序的 DLL 搜索路径，并清除继承的 PYTHONHOME，避免 GUI 的 CPU Torch 与生图 CUDA Torch 冲突。处理方式依据 [PyInstaller 外部程序说明](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#launching-external-programs-from-the-frozen-application)。

默认交付的生图权重为 [Comfy-Org 的 SD1.5 FP16 存档](https://huggingface.co/Comfy-Org/stable-diffusion-1.5)，含上游模型来源与 OpenRAIL-M 全文；它是低显存兼容模型，不宣称为最新一代生成模型。ComfyUI 和视频节点的源码、许可随引擎保留；语音模型附带模型卡，第三方权利不受项目自有部分授权文字限制。

## 验证范围

验收记录在 `reports/portraits-r126/`：人物配准与 20 个最大开口画面、整包组件检查、实际生成文件、ASR 离线加载、打包版迁移测试、源码指纹、APK 签名及完整 ZIP 回读分别记录。离线识别测试明确拒绝网络请求，并成功识别了预录语音，未打开麦克风。

本机已测图形硬件为 GTX 1650 4GB。未连接 Android 真机，也不能把同一台机器上的独立目录测试声称为所有 Windows/驱动组合验收。真实麦克风、其他显卡、云端私人账号需在对应环境验证。
