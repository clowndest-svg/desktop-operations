# r125：形象与声音

主页保持对话优先，其他功能仍在「功能」菜单。右下角固定保留「聆听」「朗读」和云雾语音球；点击「形象与声音」可选择 20 个独立写实角色，搜索名字或外观特征，并为每个角色更换、试听、记住音色。语速、音量与录制入口位于同一面板。

角色支持自然、说话、眨眼、微笑、气鼓鼓与柔和低落。表情根据助手回答中的明确文字信号进行保守匹配，否定表达「别生气」不会触发生气，严肃或悲伤内容优先柔和表情。鼠标移动时眼神轻微跟随；用户可以分别关闭眼神与表情。系统减少动态效果时停止眼神跟随、呼吸与自动眨眼，保留实际语音口型。

切换角色先确认实际音色结果再保存配置，失败会显示原因。当前引擎不提供推荐音色时保留实际声音并提示。20 个角色可以共用声音，不等于 20 种独立音色。在线音色需要联网；没有播放音频时不伪造嘴部说话。该实现使用 2D 表情图集混合，不是 Live2D 或逐音素数字人。

手机的「形象与声音」入口提供同一组角色，通话页随所选角色及回答改变表情，音色由连接电脑提供。手机选择保存在手机，电脑选择保存在电脑；用户数据与密钥不随交付包分发。

素材由内置 OpenAI imagegen 创建，原始图集、制作说明与提示词位于 assets-src/portraits/。验证报告位于 reports/portraits-r125/；Android 实机、真实麦克风环境和用户自有第三方云账号仍需在对应设备与账号下确认。
