# r128：重做人物口型/眨眼/表情，修桌面宠物切换与补充导出

2026-10-25。r128 针对「人物动起来假、桌面宠物点了没反应」重做动画合成，并把新增能力全部内嵌进包内。

## 人物动画

旧实现把「张嘴帧」「闭眼帧」「表情帧」整块矩形羽化后贴到脸上：说话时会出现浮嘴/双唇，闭眼时眉毛跟着动，切换表情时整张脸像在融化。r128 改为：

1. 以嘴唇颜色和眼睛区域生成**贴合五官的遮罩**，不再用方形/整脸贴片。
2. 张嘴使用 **4 档预生成下颌张开帧**（25/50/75/100%），口腔内贴片随档位进入；音量在档位之间平滑过渡，嘴型不是简单地把一张笑脸盖上去。
3. 眨眼只替换**眼睑区域**，眉毛和脸颊保持原位；默认每 3.6~6.2 秒一次，减少动态效果时关闭。
4. 开心/生气/柔和只替换**嘴角/眉部**区域，不再整脸羽化；说话时口型优先，表情在停顿时恢复。
5. 闲置/说话帧率提升到 20/30 fps，头部摆动和呼吸幅度调小；可见性丢失时保留慢速看门狗，动画不会因为一次 IntersectionObserver 回调丢失而永久冻住。
6. 默认角色「月汐」保留 4096×4096 基底；其余角色 1024。贴片、下颌帧和眨眼帧全部随前端包内嵌，不联网、不需要额外配置。

## 桌面宠物

功能菜单「桌面宠物」之前只切了状态：分层窗已经创建，但页面有时在 Vue 安装命令处理器之前就收到了 `alpha` 指令，窗口于是永远是一块空透明窗，看起来就是「点了没反应」。r128 在显示后持续重发 `alpha`（直到第一帧真正到达或超时），并把首帧作为确认；最终验收又发现同一场比赛会让 `wake` 也发早——窗口能画出一帧，却回到睡眠停住，看起来像「弹出来了但不动」。现在唤醒指令跟着每次 `alpha` 重发，直到首帧到达；分层窗、点击穿透和拖动路径不变。

## 其他

- **检查更新的措辞**：服务器清单比本机旧时，不再说「清单上最新的也是你手上这版」，改为明确提示「清单比你旧，别降级，先问作者」。
- 云端视频重置、媒体下载截断、流取消等上一轮修复保留。
