# r127：4K 人物、可收藏形象与完整本地能力验收

> 历史说明：r128 已重做人物口型/眨眼/表情并修复桌面宠物切换；当前交付以 [r128 交付说明](交付说明-r128.md) 为准。

2026-10-25。r127 接手 r126 候选构建，完成视频画面复验、人物清晰度提升、交付完整性和最终解压验收。

## 本轮改动

1. **默认人物 4K 基底**：20 个角色的表情素材从 512×512 提升到 1024×1024 原生分辨率；默认角色「月汐」的基底帧用 RealESRGAN x4 放大到 **4096×4096**，说话/眨眼/表情帧保留 2048×2048 的高清裁切，既保证大屏清晰度，也避免运行时同时解码六张 4K 位图（约 400 MB 内存）。桌面画布按实际显示尺寸自适应，最高 2048 px；人物按正方形绘制而不是横向拉伸，适配宽屏右侧构图。
2. **形象收藏与随机切换**：20 个角色可搜索、收藏、只看收藏、随机换一位；收藏通过软件设置（Python 后端）持久化，和角色、音色一起重启恢复，不依赖每次启动都会变化的本地页面端口。
3. **视频关键帧流程**：先生成 512 px 关键帧，再在潜空间缩放到目标尺寸并以低重绘强度生成动作。16 帧 / 256×256 / 8 fps 的正式档在本机实际解码为 16 帧、2.0 秒，抽帧能辨认主体（红鸟与树枝），不再出现候选包里的彩色噪声。细节仍受 SD1.5/AnimateDiff 与 4 GB 显存的限制。
4. **媒体下载完整性**：图片和云端视频下载共用 `media_download.py`；声明长度超限、实际字节不足、`IncompleteRead` 和主动取消都会在落盘前失败，不再把残缺媒体当成功结果。
5. **云端视频配置重置**：显式空值仍可关闭轮询/额外请求头，而「重置为出厂默认」改为删除偏好键，不再写入空串，重启后仍能回到默认契约。

|---|---|---|

| 本地图片 | ComfyUI、独立 Python、CUDA Torch、SD1.5 FP16 | 兼容的 NVIDIA 显卡与驱动；本机 GTX 1650 4GB 实测 |
| 本地短视频 | AnimateDiff 模型、视频节点、编码依赖 | 同上；低配从默认短视频档开始，生成需要等待 |
| 离线语音识别 | SenseVoiceSmall、FSMN-VAD 权重 | 麦克风与系统权限；不先下载识别模型 |
| 语音朗读与角色搭配 | Edge-TTS、20 个形象与音色绑定 | 在线音色需要联网 |

## 本轮实测

- 源码质量：`scripts/run_gates.py --frontend` 最终一轮 **4008 passed / 5 skipped**；black、ruff 通过；`mypy --strict jarvis tests` 在 409 个源文件上 0 错；前端 `vue-tsc + vite build` 通过。
- 人物素材校验：20 个角色 × 6 帧 = 120 张 1024×1024 RGBA，配准残差最大 12.01 px；默认角色基底 4096×4096，表情帧 2048×2048。
- 浏览器界面验收：20 个角色逐一切换、最大开口、视线跟随、微笑/气鼓鼓/柔和表情、真实 PCM 驱动口型与停止闭口均通过（`reports/portraits-r127/ui/`）。
- 视频：正式档 16 帧 / 256×256 / 8 fps 实际出片，162.6 秒；解码为 16 帧、2.0 秒；抽帧可辨认主体且无彩色噪声，拼图留档。
- 作者版 exe 自检：`ok/frozen/r127/author`，15 项检查全过，`source_sha256 c2143397…` 与门禁一致；exe 101,168,074 字节。
- Android：0.9.0（15），25,445,344 字节，签名沿用原密钥，APK 内 149 个前端资源与 `dist-mobile` 逐字节一致；未连接真机。
- 买家包：构建期源目录 **22,467.9 MB / 54,443 个文件**；最终 ZIP **17,889,249,359 字节（17,060.5 MB）**，SHA256 `32230588b3ca77912ca4613102bb04ae1a8eb3f9d93d70aacdecd82b1adcc0ce`；独立全 CRC 回读 **201 秒通过**，发布清单 `latest-r127.json`。
- 解压后 **22,611 MiB / 54,457 个文件**，全新目录中确认包含程序、四档模型、本地图片/视频引擎、离线识别权重、固定版 WebView2 与手机 APK；没有作者数据目录。
