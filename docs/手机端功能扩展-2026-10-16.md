# 手机端 0.5.0 功能扩展

本轮将手机端扩展为随身 AI 工作台。参考 Chatbox 的提示词与引用、Cherry Studio Mobile 的助手与资料管理思路，使用本项目现有 Vue / Capacitor 架构独立实现。

参考来源：

- [Chatbox](https://github.com/chatboxai/chatbox)
- [Cherry Studio Mobile](https://github.com/CherryHQ/cherry-studio-app)

## 功能与入口

| 功能 | 使用方式 |
|---|---|
| 多会话、全文搜索 | 左上角「会话」，按标题、消息和已附资料搜索手机历史 |
| 置顶、重命名、归档 | 每段会话下方操作，归档后可以从「归档」找回 |
| 独立草稿 | 每段手机会话保存自己的未发送文字，切换和重开后恢复 |
| 聊天内搜索 | 会话抽屉「搜索本段聊天」，上下切换匹配消息 |
| 8 类助手 | 「＋ → AI 工作台 → 助手」，日常、写作、翻译、学习、编程、会议、计划、阅读 |
| 会话指令 | 工作台「助手」中为当前会话保存自定义指令 |
| 16 个变量模板 | 工作台「提示词」，填写变量后放入输入框，检查后自行发送 |
| 自建提示词 | 自定义名称、分类与正文，支持变量、编辑、搜索和删除，最多 50 条 |
| 引用与追问 | 回答下方操作菜单，将选中内容放入下一条提问草稿 |
| 精简、转清单 | 生成带原文的草稿，不自动发送或执行操作 |
| 从消息处分支 | 将选中消息以前的内容复制到新手机会话，原会话保留 |
| 重新回答 | 独立模式建立新分支重问；图片需要重新选择，电脑模式仅追加提问 |
| 收藏回答 | 工作台「收藏」搜索、复用、导出及取消收藏，最多 200 条 |
| 离线笔记 | 工作台「笔记待办」，新建、编辑、搜索、标签、置顶、导出，聊天消息可直接存笔记 |
| 待办 | 新建待办、标记完成、重新打开，按未完成与已完成筛选 |
| 笔记资料问答 | 「交给 AI 阅读」将笔记附到输入框，发送时才交给当前模型 |
| 文本文件问答 | 「＋ → 读文件」，支持 TXT / Markdown / CSV / JSON / LOG / TS / JS / PY / HTML / CSS |
| Markdown 导出 | 当前对话、单条收藏和笔记均可导出；Android 使用系统位置选择器 |
| 内容备份与恢复 | JSON 备份包含手机会话、草稿、指令、收藏、笔记、待办、提示词与阅读偏好；校验后确认替换 |
| 阅读偏好 | 标准 / 大字，紧凑消息操作；原有浅色 / 深色继续可用 |
| 上下文设置 | 最近 10 / 30 / 60 条消息，实际作用于独立模式请求 |
| 手机工具开关 | 可以只聊天；关闭时即使模型返回操作调用也不会执行 |
| 内容统计 | 手机会话、归档、消息、字数、收藏、笔记、待办与存储占用，不冒充 token 或费用统计 |

## 数据与兼容

- 兼容原有单段历史，以及不含新字段的 v1 工作台备份；已有用户不必清空数据。
- 手机模型配置和电脑令牌沿用 Android Keystore 加密存储，不放入工作台备份。
- 本地笔记、草稿、提示词和收藏的保存不会触发模型请求。发送问题与资料时才会传给所配置的模型端点。
- 电脑历史继续由电脑维护，手机分支和手机助手只在独立模式使用。手机不提供删除电脑原记录的能力。
- 保留 100 段手机会话，每段最多 60 条消息；文件最多 128 KB / 24000 字，完整备份最多 8 MB，笔记与待办合计最多 100 条。
- 恢复会替换手机工作区，界面先展示条目数并要求确认，建议事先保存当前备份。
- 图片不保存在本地聊天历史中。附加的文本资料保留原文以便后续问答，并以文件名在气泡中展示。

## 验证与交付依据

自动化测试与浏览器场景验证实际请求、数据迁移、草稿恢复、分支独立性、笔记待办、模板、搜索、工具禁用、导出恢复及窄屏布局。浏览器模型回复使用明确标注的测试响应，不作为真实云模型验证。

验证脚本：`scripts/test_mobile_runtime.mjs`、`scripts/verify_mobile_workspace_ui.mjs`、`scripts/verify_mobile_productivity_ui.mjs`；内容回归在 `frontend/tests/mobileWorkspace.test.mjs`、`frontend/tests/mobileProductivity.test.mjs`。

当前 `adb devices` 没有连接设备。Android 签名、资源和版本校验不能代替手机系统文件选择器、输入法、权限、语音引擎及旧安装数据迁移的真机验收。完整门禁、签名 APK 和交付 ZIP 的实际结果以本轮 QA 回执为准。
