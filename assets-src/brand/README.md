# 小夜品牌素材

`xiaoye-logo.jpg` 是用户在 2026-10-25 提供的品牌原图，所有平台标识均从该文件派生。

`portrait.png`、`speaking.png`、`blink.png` 为 imagegen **内置工具**生成，保存在本目录作为制作源；最终运行资源在 `frontend/src/assets/brand/`。未采用最初生成的高饱和动漫稿。

最终提示词：以 logo 的黑发、月饰为轻度参考，生成约 25 岁成年东亚女性的写实正面头肩肖像。自然皮肤纹理、深棕色眼睛、淡妆、黑色长发、小巧银色月亮发饰和耳饰、简约炭灰色衣服，柔和低饱和冷月光、真实透明背景。嘴唇轻闭、眼睛睁开。禁止动漫、霓虹、紫色发光头发、过度饰品、塑料皮肤、文字和边框。

说话表情编辑：保持原图尺寸、人物位置、皮肤、眼睛、头发、服装和光线不变，仅将嘴唇改为自然小幅张开的说话嘴形，可见少量上齿。

眨眼表情编辑：保持原图位置、闭合嘴唇及所有其他内容不变，仅将双眼改为自然轻闭的眼睑和睫毛。

用户提供的抖音截图只用于界面构图参考，没有提取其中人物、视频、音频或其他第三方媒体。本轮写实人物并非真实演员的授权肖像，也不宣称复刻视频中的人物。

重建 WebP/Android 资源：`python scripts/prepare_brand.py`。重建 exe 图标：`python scripts/make_icon.py`。两项需要项目桌面依赖 Pillow。运行软件不需要图像生成服务。
