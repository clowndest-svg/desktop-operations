# 小夜写实形象素材

20 位虚构成年女性，由本次任务中的内置 OpenAI imagegen 工具生成；未下载或挪用抖音视频人物、明星照片或 GitHub 作者的角色素材。p01 延续用户已确认的月饰、黑发、灰色服装风格，其余角色改变脸型、发型、眼镜及服装。

每个 pNN.png 是独立角色的六表情图集，按 2 列 3 行排列：自然、说话、闭眼、微笑、气鼓鼓、柔和低落。统一提示词见 prompts.json，角色名字、特征和推荐音色见 frontend/src/avatar/portraitCatalog.ts。生成结果并非分层 Live2D 模型；运行时采用面部局部混合、轻微眼部纹理形变与实际播放音频的电平驱动口型，不声称逐音素对嘴或识别用户真实情绪。

`scripts/prepare_portraits.py` 负责等比例切图、WebP、缩略图与面部位置校准。构建工具使用 Pillow、NumPy、OpenCV 4.13；OpenCV 仅用于素材制作，未加入应用运行依赖。输出在 frontend/src/assets/portraits/，每次只解码选中的 6 张表情，缩略图按需加载。原图保留便于后续重新制作。

20 个形象共享部分可用音色，并非 20 个不同语音模型。推荐包含普通话和明确标注的台湾国语；允许改配现有内置或用户录制音色。桌面设置由 Python 持久化，手机形象偏好保存在本手机，手机语音使用已配对电脑提供的实际引擎。
